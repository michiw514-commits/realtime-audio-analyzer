# Universal Signal Analysis Platform 🚀

## Концепция
Универсальная платформа для приема, анализа и управления сигналами любой природы. 
Проект начинается с анализа звуковых сигналов, но архитектура позволяет подключать 
любые источники: АЦП, лазерные диоды, датчики, SDR и т.д.

## Ключевая особенность: замкнутый цикл управления
Система не только анализирует сигнал, но и может управлять источником 
на основе результатов анализа. Например, для лазерного диода:
1. Задаем целевую частоту излучения
2. Система анализирует текущий сигнал
3. Через PID-регуляторы меняет ток и температуру
4. Частота стабилизируется с высокой точностью

## Модульная архитектура
- **signal_source/** - абстрактный интерфейс для любых источников сигнала
- **signal_processing/** - буферизация, FFT, спектральный анализ
- **control/** - PID-регуляторы, обратная связь, стабилизация
- **gui/** - визуализация и управление

## Применения
- Анализ звука и вибраций
- Управление лазерными диодами
- Обработка сигналов с АЦП
- Спектроскопия
- Научные эксперименты
- Образовательные проекты
