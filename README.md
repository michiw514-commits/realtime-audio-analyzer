# Real-Time Audio Analyzer 🎵

## Описание проекта
Real-Time Audio Analyzer - это модульный программный комплекс для анализа звуковых сигналов в реальном времени. Проект разрабатывается командой из трех человек в рамках учебных курсов и исследовательских работ.

### Возможности
- Генерация тестовых сигналов (синусоидальные, сложные формы)
- Буферизация аудиоданных с кольцевым буфером
- Быстрое преобразование Фурье (FFT) для спектрального анализа
- Визуализация сигналов во временной и частотной областях
- Модульная архитектура для легкого расширения

## 🛠️ Технологии

- **Язык:** C++17

- **Алгоритмы:** Быстрое преобразование Фурье (Cooley-Tukey)
- **Контроль версий:** Git + GitHub
