# Audio Spectrum Analyzer

Real-time audio spectrum analyzer with FFT visualization. C++/Qt student project.

## Features
- Real-time audio capture from microphone
- FFT-based frequency analysis
- Spectrum visualization with Qt Charts
- Peak frequency detection
- Support for USB audio devices

## Quick Start

### Prerequisites
- Qt 6.5+ with Qt Charts module
- C++17 compiler
- CMake 3.16+
